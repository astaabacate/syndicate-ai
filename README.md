# SYNDICATE.AI — Autonomous AI Content Repurposing Engine (B2B Mobile Hub)

Operação autônoma de Micro-Repurposing B2B para podcasters e canais no YouTube dos EUA, Reino Unido, Canadá e Brasil.

## 🚀 Como Rodar pelo Celular / Vercel (100% Grátis)

### Opção 1: Deploy em 1 Clique na Vercel (Recomendado para Celular)
1. Conecte sua conta do GitHub na [vercel.com](https://vercel.com) (grátis).
2. Selecione este repositório `syndicate-ai`.
3. Clique em **Deploy** (sem precisar mexer em nenhuma configuração).
4. Em 30 segundos você terá um link público seguro (ex: `https://syndicate-ai.vercel.app`) para abrir no navegador do celular e instalar na tela inicial como PWA!

### Opção 2: Rodar Localmente
```bash
npm install
npm run dev
```

## 🛠️ Tecnologias
- React 19 + Vite 6
- Tailwind CSS v4
- Lucide React (mobile-first icons)
- Canvas Confetti
- LocalStorage persistence
- Standalone AI heuristic content transformation engine (zero cost)
- Native `mailto:` deep-linking for mobile mail clients
